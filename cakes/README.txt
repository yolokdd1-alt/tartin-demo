Оксана Бугаева — кликабельный прототип

Откройте index.html в современном браузере. Интернет не требуется.
Все изображения лежат в папке assets; сохраняйте её рядом с index.html.

Сценарий: Главная → Размер → Начинка → Оформление → Дата → Заявка отправлена.
Кнопки верхней панели переключают экран и мобильную/компьютерную версию.
«Области клика» подсвечивает активные зоны готовых макетов.
На телефоне прокручивайте страницу внутри рамки; нижняя кнопка закреплена.

Это прототип из статичных изображений, а не разработанный конструктор.
Цвета, поля и параметры показаны фиксированным примером.
Начинки, дата и вес требуют согласования с кондитером.
Заявки и внешние сообщения не отправляются. Платежей нет.
Копирование использует локальный буфер обмена или показывает текст для ручного копирования.

На главную встроен живой анимированный первый экран. Остальные разделы — согласованный макет.
Отдельная анимационная проба сохранена в motion.html.
Реальные данные пользователей в прототип не вводятся.

Исправление качества: главная и компьютерные шаги переведены с PNG-экранов на HTML.
Мобильные шаги сохранены как исходные макеты.
Фотографии ягодного и детского тортов взяты из старого макета и ограничены разрешением источника.
Для публикации нужны исходные фотографии Оксаны.
